# Katalog

`catalog.csv` bu klasöre konursa derleme sırasında eklentiye eklenir ve Vefeyât penceresi
onu kendiliğinden yükler. Dosya GitHub Pages üzerinden **herkese açık** yayımlanır ve depo
geçmişinde kalır; yayın hakkınız olduğundan emin olun.

Biçim: noktalı virgülle ayrılmış UTF-8 CSV, başlık satırı
`Kısa Ad;Tam Ad;Orijinal Ad;Vefat Tarihi;Tanıtım;Kaynak Link`.
