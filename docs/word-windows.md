# Windows masaüstü Word eklentisi

Güncel sürüm Word şeridinde **Vefeyât** sekmesi oluşturan yerel COM eklentisidir. Kurulum ve kullanım için [Windows kullanım kılavuzunu](../desktop/KULLANIM.md) izleyin.

Bu sürüm Office.js manifesti, HTTPS adresi veya ağ paylaşımı kullanmaz. Önceki web eklentisi belgeleri yerel masaüstü sürümü için geçerli değildir.
