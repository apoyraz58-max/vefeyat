# Windows yerel kurulum

Vefeyât artık Windows masaüstü Word’e yerel COM eklentisi olarak kurulur. Güncel kurulum, veri konumu, yedekleme ve kaldırma yönergeleri [Windows kullanım kılavuzundadır](../desktop/KULLANIM.md).

Kurulum için **Kur.cmd** kullanılır. Önceki Docker/Caddy/PostgreSQL kurulumu bu sürüm için gerekli değildir.
